# Pulse

Pulse is a real-time responsive web messaging application.

## Key Features
- High-performance REST polling messaging engine
- Role-based permissions, channel permission overrides, and role ordering
- Channel management and user moderation
- Direct messaging, group DMs, and friend requests
- Message replying, inline editing, and deletion with permission gating
- Custom server creation and management

## Development

```bash
npm install
npm run dev
npm run build
```
